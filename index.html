INTELIGÊNCIA ARTIFICIAL (OPCIONAL)

Para respostas livres, você pode conectar uma chave de API de um provedor com plano gratuito. Sem chave, o Jarvis continua funcionando com comandos locais.

Aviso: esta versão chama a API diretamente do navegador. A chave fica salva apenas neste aparelho/navegador, mas pode ser exposta ao usar a página. Não use uma chave com acesso a dados ou cobrança importantes; para um projeto público, o ideal é um servidor intermediário.

Obtenha a chave no Google AI Studio. A disponibilidade e os limites gratuitos dependem da conta e podem mudar. Nunca coloque a chave dentro do código HTML ou no GitHub.

ATALHOS DO CELULAR E PESQUISA

O navegador pode pedir confirmação para abrir links. Por segurança, o Jarvis não pode controlar livremente outros aplicativos ou alterar configurações do Android.

TAREFAS E LEMBRETES LOCAIS

As tarefas ficam salvas neste navegador. Esta versão não envia notificações automáticas se a página estiver fechada.
